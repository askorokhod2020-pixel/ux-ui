# ux-ui

Личная библиотека скиллов для Claude Code: UX/UI, сайты, презентации, приложения, диджитал-дизайн, моушен.

## Структура

```
skills/
  web/                    сайты, лендинги, вёрстка, UI-полировка
  presentations/          презентации и слайды
  apps/                   мобильные и веб-приложения, дизайн-системы
  digital-design/         бренд, графика, соцсети, карусели
  motion/                 анимация, видео, интерактив
  research-and-strategy/  брифы, PRD, ресёрч, UX-исследования
templates/                шаблон нового скилла
scripts/
  install.sh              подключает скиллы из репозитория в ~/.claude/skills
  sync.sh <имя> <раздел>  забирает скилл из ~/.claude/skills в репозиторий
```

Один скилл = одна папка с файлом `SKILL.md` (плюс при необходимости `references/`, `assets/`).

## Использование

```bash
./scripts/install.sh              # подключить все скиллы (симлинки)
./scripts/sync.sh my-skill web    # добавить скилл в раздел web
```

Симлинки означают, что правки в репозитории сразу работают в Claude Code, а `git push` делится ими.

## Новый скилл

Скопируй `templates/SKILL.md` в `skills/<раздел>/<имя-скилла>/SKILL.md` и заполни.
