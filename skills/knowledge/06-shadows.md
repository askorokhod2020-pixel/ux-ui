# Тени

Тень в интерфейсе показывает **высоту**: что над чем лежит, что можно поднять, нажать, перетащить. Это не декор.

## 1. Физика, которую повторяем
- **Один источник света** на весь продукт, обычно сверху (чуть сверху-слева или строго сверху). Тени у всех элементов падают в одну сторону.
- Чем выше объект, тем тень **больше, мягче и светлее**, и тем дальше она смещена.
- Чем ближе к поверхности, тем тень **меньше, резче и темнее**.
- В реальности тень состоит из двух частей: **контактной** (короткая, плотная, у самого края) и **рассеянной** (большая, мягкая). Поэтому хорошая UI-тень — это 2–3 слоя.

## 2. Параметры
- Смещение по Y больше, чем по X (обычно X = 0).
- Blur ≈ 2× смещения по Y.
- Непрозрачность низкая: 4–16% на слой.
- Цвет тени — не чистый чёрный, а тёмный оттенок фона или бренда (например `hsl(220 40% 10% / 0.1)`). Так тень не «грязнит».
- Spread обычно 0 или отрицательный, чтобы тень не вылезала по бокам.

## 3. Шкала высот (пример)
| Уровень | Для чего | Значение |
|---|---|---|
| 0 | плоская поверхность | нет тени, можно обводку 1 px |
| 1 | карточка, кнопка | `0 1px 2px rgb(0 0 0 / .06), 0 1px 3px rgb(0 0 0 / .10)` |
| 2 | карточка при hover, липкий хедер | `0 2px 4px rgb(0 0 0 / .06), 0 4px 8px rgb(0 0 0 / .08)` |
| 3 | выпадающие меню, поповеры | `0 4px 8px rgb(0 0 0 / .06), 0 12px 24px rgb(0 0 0 / .10)` |
| 4 | модальные окна, диалоги | `0 8px 16px rgb(0 0 0 / .08), 0 24px 48px rgb(0 0 0 / .16)` |

Уровней 3–5, не больше. Каждый закреплён за ролью.

## 4. Правила
- Тень назначают по роли элемента, а не «чтобы было красиво».
- На hover элемент поднимается на 1 уровень (тень растёт, можно `translateY(-2px)`). При нажатии опускается.
- Не смешивай тень и заметную обводку на одном элементе без причины. Выбирай одно.
- Вложенные элементы внутри карточки тень не получают.
- **Тёмная тема:** тени почти не видны. Высоту показываем светлотой поверхности (выше — светлее) и тонкой светлой обводкой сверху.
- Цветные «светящиеся» тени (glow) — только как осознанный стилистический приём и только для одного элемента.
- Внутренняя тень (inset) — для «утопленных» элементов: поля ввода, трек слайдера, нажатое состояние.
- Размытие фона (backdrop blur) — для слоёв поверх контента (шторки, навбар), с подложкой, чтобы текст читался.

## Ошибки
- Тени в разные стороны у разных элементов.
- Жёсткая тёмная тень `0 0 10px #000`.
- Одна и та же тень на всём подряд — высота ничего не значит.
- Тени на каждом уровне вложенности (карточка в карточке в карточке).
