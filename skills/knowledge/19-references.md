# База сайтов с референсами

Все ссылки из базы знаний, собранные по назначению, и правила работы с референсами.

## Как работать с референсами
1. **Сначала задача, потом референсы.** Ищи под конкретный вопрос: «как показать тарифы для 3 аудиторий», «как сделать hero для кофейни с акцентом на атмосферу». Не листай галереи бесцельно.
2. **«Уровень нормы».** Перед стартом посмотри 20–30 сильных работ в нише и вокруг. Это твоя планка качества: твой результат должен быть не хуже среднего из них.
3. **Разбирай, а не копируй.** Для каждого референса запиши, что именно в нём работает: сетка, ритм, типографика, приём с фото, анимация. Бери приёмы, а не экраны.
4. **Минимум 3 источника на одно решение.** Одна картинка — копия, три — исследование.
5. **Референсы из разных областей.** Журналы, плакаты, архитектура, упаковка — так появляется своё решение, а не повтор галереи.
6. **Собирай в мудборд**: Figma-доска или Pinterest по проекту, с подписями «что взять».
7. **Для UX — реальные продукты, а не концепты.** Dribbble-концепты красивы, но часто не работают. Флоу смотри в живых приложениях (Pageflows, Mobbin).

## Страницы базы, которые остались без разбора
В базе это в основном ссылки, видео и картинки без текста, поэтому в правила они не вошли. Открывай их в Notion напрямую:
- Компоненты Figma · AUTO LAYOUT · UI кит · Дизайн системы
- Иконки · Графики и дашборды
- Карточки с тарифами для сайта · Создание кейса · Скрины UX кейс статьи
- Сервисы с мокапами · Сервисы с градиентами · 3D стоки
