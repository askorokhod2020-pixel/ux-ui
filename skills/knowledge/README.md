# База знаний: правила по темам

Правила собраны на основе базы [«Женя Кузнецова — материалы по дизайну»](https://app.notion.com/p/da140cbc8984484cae3ca7c9d63b352d) в Notion. В базе почти всё — подборки ссылок, поэтому правила дописаны по общепринятой практике, а ссылки из базы разложены по темам в конце каждого файла. Темы, которых в базе не было (эвристики Нильсена, user stories, JTBD), написаны по первоисточникам, это отмечено в файлах.
