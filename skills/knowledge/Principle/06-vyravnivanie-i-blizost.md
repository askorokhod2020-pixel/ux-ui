# Выравнивание и закон близости

## Закон близости (гештальт)

Объекты рядом воспринимаются как одна группа, объекты на расстоянии —
как раздельные.

- **Главное правило (Ян Чихольд): внутренние расстояния меньше внешних.**
  Заголовок, картинка и подпись одного блока стоят ближе друг к другу,
  чем к соседнему блоку — и мозг читает их как одно целое.
- Связанное — рядом: автор у цитаты, цена у товара, подпись у фото,
  подводка у заголовка.
- **Пустое пространство** вокруг групп отделяет смысловые блоки и даёт
  макету «дышать».
- Отступы — по модулю: внутри блока меньше (8–16 px), между блоками
  больше (32–64 px).

## Выравнивание

Выравнивание создаёт визуальную связь между элементами даже в разных частях
макета и задаёт невидимые направляющие, по которым скользит взгляд.

**Виды:**
- **По левому краю** — основной и самый удобный для чтения.
- **По правому краю** — редко: афиши, плакаты, короткие акценты.
- **По центру** — для коротких заголовков и небольших блоков;
  плохо читается на длинных абзацах.
- **По ширине** — только в широких колонках и с переносами, иначе «дыры».
- **По базовой линии и краям объектов** — картинки, иконки, кнопки стоят
  по общему вертикальному или горизонтальному ребру.

**Правила:**
- Каждый элемент выровнен по чему-то: по краю, по сетке, по другому элементу.
- В одном макете — один основной край выравнивания; смешивать центр,
  лево и право без системы нельзя.
- Иконка рядом с текстом — по высоте заглавных букв или по центру строки.
- Подводка, заголовок и подпись одного блока — по одному краю.

## В нашем бренде

Основное — **по левому краю** (статьи и всё, что читают по F-паттерну).
**По центру** — только обложки с центральной композицией и коротким хуком.
**По правому** — очень редко, афиши и плакаты. Подробно —
`../design-rules.md`; это сильнее общего правила выше.

## По форматам

- **Reels:** подводка, заголовок и подпись — на одной линии края; иконка —
  по высоте букв.
- **Карусели:** один край выравнивания на всех слайдах; номер слайда,
  заголовок и текст — по общим направляющим.
- **Сайты:** колонки сетки, общие левые края у заголовков, текста и кнопок.

## Ошибки

- Одинаковые отступы везде — группы не читаются.
- Подпись ближе к чужой картинке, чем к своей.
- Элементы «почти» выровнены — сдвиг на несколько пикселей выглядит как брак.
