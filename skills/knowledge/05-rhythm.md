# Ритм

Ритм — это закономерное повторение элементов и интервалов. Он ведёт взгляд, создаёт ощущение порядка и задаёт темп чтения страницы. Без ритма страница — набор случайных блоков, а с ритмом без акцентов — монотонная лента.

## 1. Виды ритма
| Вид | Как устроен | Пример |
|---|---|---|
| **Регулярный (метр)** | одинаковые элементы через одинаковые интервалы | сетка карточек, список |
| **Чередующийся** | два типа элементов по очереди | «текст слева / фото справа», потом наоборот |
| **Нарастающий / убывающий** | элементы постепенно меняют размер, цвет, плотность | шаги процесса, таймлайн, цены от базового к максимальному |
| **Свободный (плавный)** | повторение с вариациями, органичное | промо-сайты, editorial-вёрстка |
| **Прогрессивный** | последовательность, которая ведёт к кульминации | лендинг, подводящий к CTA |

## 2. Из чего складывается ритм в вебе
1. **Вертикальные интервалы.** Одинаковый отступ между секциями (например 120 на десктопе) и внутри секций (по шкале 4/8). Это главный ритмообразующий фактор.
2. **Чередование фонов.** Светлая секция → акцентная → светлая. Не больше 2–3 вариантов фона.
3. **Чередование композиций.** Текст + фото → сетка карточек → крупная цитата → текст + фото (зеркально).
4. **Повторяющиеся элементы.** Заголовок секции всегда одного вида и в одном месте; одинаковые карточки; одинаковые иконки.
5. **Плотность.** Плотная секция с данными, затем «воздушная» с одной фразой. Это смена темпа, как пауза в музыке.

## 3. Правила
- Задай базовый модуль (8 px) и строй все отступы кратными ему.
- Один отступ для одинаковых ситуаций по всей странице: все секции разделены одинаково, все карточки — одинаково.
- **Ритм + акцент.** Ритм создаёт фон, акцент его нарушает. Разрыв ритма (крупное фото на всю ширину, смена фона, цифра на весь экран) должен быть осознанным и редким: 1 на 3–4 секции.
- Не больше 3 типов композиции секций на странице. Больше — ритм рассыпается.
- Повторяемость компонентов: одинаковые сущности выглядят одинаково. Карточка тарифа не меняет структуру от тарифа к тарифу.
- Ритм читается при быстром скролле: прокрути страницу быстро и проверь, видны ли такты (секции) и куда «бьёт» каждый такт.

## 4. Ритм в тексте
- Межстрочный интервал задаёт микро-ритм. Базовая линия текста привязывается к сетке 4/8.
- Отступы абзацев, подзаголовков, врезок кратны межстрочному.

## Ошибки
- Каждая секция со своими отступами («на глаз»).
- Все секции одинаковые: ритм есть, но нет развития и акцентов.
- Чередование ради чередования: фото слева-справа без смысла.
- Слишком много типов секций и фонов.
