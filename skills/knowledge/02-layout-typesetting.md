# Вёрстка и типографика текста

Как сверстать текст, чтобы его читали: статьи, лонгриды, описания, интерфейсные тексты. Выбор шрифтов — в [01-typography.md](01-typography.md).

## 1. Колонка текста
- Ширина колонки 600–720 px на десктопе (около 65 знаков). Текст на всю ширину экрана не читают.
- Колонка выравнивается по левому краю. Выключку по ширине в вебе не используем: появляются «реки» пробелов.
- Центрируем только короткие блоки до 2–3 строк (заголовок hero, подпись).
- Медиа может выходить за колонку текста (врезки, фото на всю ширину), а текст из неё не выходит.

## 2. Вертикальная структура статьи
- Отступ над заголовком больше, чем под ним: заголовок «принадлежит» следующему абзацу. Пример: 48 сверху, 16 снизу.
- Абзацы разделяем отступом (0.75–1 межстрочного), а не красной строкой. Одно из двух, не оба сразу.
- Абзац — 3–6 строк. Стена текста без подзаголовков и списков не читается: подзаголовок каждые 3–5 абзацев.
- Лид (первый абзац) крупнее основного текста на 1–2 ступени шкалы.
- Цитаты, врезки, выноски нарушают монотонность колонки, но подчиняются той же сетке.

## 3. Русская типографика (обязательно)
| Правило | Неправильно | Правильно |
|---|---|---|
| Кавычки-ёлочки, внутренние — «лапки» | "Слово" | «Слово», «Он сказал „да“» |
| Тире — длинное, с пробелами | Москва - столица | Москва — столица |
| Дефис — внутри слова | кое—где | кое-где |
| Короткое тире в диапазонах | 10-20 | 10–20 |
| Неразрывный пробел после предлогов, союзов, перед тире | | в&nbsp;доме, 10&nbsp;кг, 2026&nbsp;г. |
| Многоточие одним символом | ... | … |
| Знак рубля и разряды | 1000000 руб | 1 000 000 ₽ |
| Знак минуса | -5 | −5 |
| Ё там, где важно для смысла | все (всё) | всё |

- Висячие предлоги и союзы в конце строки привязываем к следующему слову неразрывным пробелом.
- Одно слово на последней строке абзаца («вдова») убираем правкой текста или `text-wrap: pretty`.
- Переносы в вебе: `hyphens: auto` с `lang="ru"` только для узких колонок. В заголовках переносов нет.

## 4. Цифры и данные
- В таблицах моноширинные цифры, выравнивание по правому краю.
- Разряды отделяем узким неразрывным пробелом: 12 500.
- Единицы измерения не отрываются от числа.

## 5. Ссылки и выделения
- Ссылки в тексте подчёркнуты (можно тонко, с `text-underline-offset`).
- Выделяем жирным только ключевые слова, не больше 1–2 на абзац. Если жирного много, выделения нет.
- Курсив — для терминов, названий, иноязычных слов.

## 6. Интерфейсные тексты
- Заголовки и кнопки пишем с заглавной только первого слова, без точки в конце.
- Подписи к полям и пункты меню — существительные или глаголы, без лишних слов.
- Одинаковые сущности — одинаковые слова по всему продукту.

## Чек-лист вёрстки текста
- [ ] Колонка ≤ 75 знаков, выравнивание по левому краю
- [ ] Отступ над заголовком больше, чем под ним
- [ ] Кавычки «ёлочки», тире «—», диапазоны «–»
- [ ] Неразрывные пробелы после предлогов и между числом и единицей
- [ ] Нет висячих предлогов и «вдов»
- [ ] Подзаголовки каждые 3–5 абзацев
